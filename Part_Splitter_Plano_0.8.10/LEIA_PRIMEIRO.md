# Como usar

1. Extraia o ZIP inteiro.
2. Abra PLANO_0.8.10.html para ler o plano com as capturas.
3. No Antigravity, forneça PLANO_0.8.10.md, NOTAS_CODIGO.md e acesso a este diretório.
4. A base real está em base/chest_part_splitter-0.8.9.zip. Os casos estão em casos/; preserve os originais.
5. Instrua o agente: “Siga o plano por etapas e gates. Reproduza antes de corrigir; declare testes pendentes. Comece pelo baseline e DEV-01/DEV-03.”

A numeração 0.8.10 é proposta. Este pacote é uma especificação de desenvolvimento, não uma extensão corrigida. Os arquivos .blend não foram executados nesta análise.
Os snippets são da extensão do usuário; código de outras extensões é referenciado por links e finalidade, não incorporado. Referências externas devem ter sua revisão/commit registrados pelo implementador.
