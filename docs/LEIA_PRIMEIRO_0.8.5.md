# Como usar este pacote

1. Extraia o ZIP.
2. No Antigravity com Gemini Pro, abra o repositório atual da extensão.
3. Envie `PROMPT_GEMINI_PRO.md` e diga: **Leia integralmente este documento, confronte cada evidência com o código atual e implemente as correções por etapas, executando os testes exigidos.**
4. As quatro imagens na pasta `imagens` são esquemas explicativos originais. Envie-as junto se quiser contexto visual; nenhuma é uma captura de execução do Blender.
5. A pasta `referencia_085/src` contém cópias dos arquivos da 0.8.5 citados na análise. São evidências, não arquivos corrigidos. Não copie esses arquivos sobre seu repositório.

O documento contém referências oficiais, passos para reproduzir os bugs, comportamento esperado, alternativas de implementação e a matriz de comprovação. O trabalho não fica validado apenas pela leitura ou pelo changelog: precisa ser testado no Blender. Não há capturas reais da 0.8.5 neste pacote.
