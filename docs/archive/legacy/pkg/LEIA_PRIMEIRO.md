# Usar o pacote

1. Extraia todo o ZIP. Abra PLANO_0.8.11.html para leitura e GALERIA.html para as evidências.
2. No Antigravity, forneça o diretório e PLANO_0.8.11.md como instrução principal. AUDITORIA_CODIGO.md traz achados e linhas; REGISTRO_RELATOS.md conserva todos os relatos.
3. Extraia base/chest_part_splitter-0.8.10.zip no projeto de trabalho e preserve o original.
4. Trabalhe em cópias de casos/Padrao_1.blend, Teste_3.blend e Teste_4.blend. Nem seleções nem resultados dos arquivos foram verificados aqui.
5. INVENTARIO_BLENDER.py é helper opcional somente leitura, para executar no Blender com --disable-autoexec. O helper passou AST, não foi executado no Blender.
6. Siga gates e teste antes/depois. O plano exige 0.8.11; 1.11 no histórico era nomenclatura anterior.

Este pacote é um plano técnico, não extensão corrigida. Compatibilidade/printabilidade/picking ainda exigem testes reais. Referências externas são links; nenhum código externo foi incorporado como solução pronta.
